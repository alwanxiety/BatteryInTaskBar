# BatteryInTaskBar 1.0.0

Первый публичный релиз виджета заряда для панели задач Windows 11.

## Что внутри

- Плитка заряда беспроводной мыши.
- Вторая плитка для AirPods / Beats: заряд левого, правого наушника и кейса.
- Перетаскивание по свободным ячейкам, обмен плиток с живым предпросмотром.
- Плавное появление и скрытие плитки наушников.
- Темы «Матовая», «Тёмная», «Светлая».
- Кэш последних показаний — без «Поиск устройства…» после перезапуска Explorer.
- Отслеживание Bluetooth-подключения без мигания из-за пауз BLE-рекламы.
- Диагностический отчёт по пяти кликам на названии устройства в меню мыши.
- Поддержка Logitech, Razer, Red Square / VXE / ATK / VGN, Compx / Attack Shark и
  большинства мышей со стандартным HID Battery Strength.

## Установка

1. Скачайте ZIP и распакуйте в постоянную папку (например,
   `%LOCALAPPDATA%\BatteryInTaskBar`). Не запускайте из временной папки.
2. Запустите `injector.exe`.
3. Включите «Запускать при старте системы» в меню мыши, если нужно.

`injector.exe --watch` переинжектит виджет после перезапуска Explorer.

## SmartScreen

SmartScreen может предупредить при первом запуске — это нормально.

## Проверка целостности

В релизе есть `SHA256SUMS.txt`. Сверьте хэши:

```powershell
Get-FileHash .\taskbar_mod.dll, .\injector.exe -Algorithm SHA256
```
