# BatteryInTaskBar 1.0.6

## Attack Shark

- Мыши Attack Shark X6 и родственные модели на ресиверах Beken (X11, R1, X3,
  X3 Max, M3, Inphic) теперь показывают заряд в виджете. Для X6 проверено
  на реальной мыши.
- Если мышь подключена кабелем, виджет показывает зарядку и последний
  известный процент. Живой процент в кабельном режиме Windows не передаёт.
- Если индикатор заряда мыши залип (например, всегда показывает 100 %),
  через сутки рядом с процентом появляется «(?)», а в меню — пояснение.
  Это подсказка, а не исправление индикатора самой мыши.

## Обновление из виджета

- При запуске виджет сам проверяет, есть ли новая версия.
- Внизу меню мыши — «Версия: …» и две маленькие кнопки: **↻** проверить
  и **↑** установить.
- Если обновление есть, на стрелке **↑** появляется синяя точка.
- Нажали **↑** — виджет тихо обновился и перезапустился. Окон обновлятора
  пользователь не видит.
- Пока идёт проверка, в футере видно «Проверка…», затем результат:
  «Обновление X», «Обновлений нет» или «Ошибка проверки».

## Важно

- Первую версию с обновлением нужно установить вручную; дальше обновления
  идут из меню виджета.
- Папка программы должна быть записываемой (не `Program Files`).
- Файлы пока без подписи, поэтому SmartScreen может предупреждать.
