# BatteryInTaskBar 1.0.4

Исправление: виджет больше не пропадает при превью окна на панели задач.

## Что изменилось

- Всплывающие окна оболочки Windows 11 (в том числе превью окна при наведении
  на кнопку панели задач) — это tool-окна без кнопки на панели задач. Теперь
  они не считаются полноэкранным приложением: виджет остаётся на месте, опрос
  HID не приостанавливается.
- Дополнительно исключены все XAML-окна оболочки и `TaskListThumbnailWnd`.
- Настоящие полноэкранные игры и видео по-прежнему скрывают виджет.
- В журнал добавлена диагностика: класс, размер и pid окна, которое детектор
  принял за полноэкранное.

## Установка

1. Скачайте ZIP и распакуйте в постоянную папку (например,
   `%LOCALAPPDATA%\BatteryInTaskBar`).
2. Закройте старый виджет через меню мыши («Закрыть виджет»), если он запущен.
3. Запустите `injector.exe`.

## SmartScreen

SmartScreen может предупредить при первом запуске — это нормально.

## Проверка целостности

```powershell
Get-FileHash .\taskbar_mod.dll, .\injector.exe -Algorithm SHA256
```

Сверьте с `SHA256SUMS.txt`.
