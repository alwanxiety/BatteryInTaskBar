# BatteryInTaskBar 1.0.2

Исправление стабильности и производительности.

## Что изменилось

### Стабильность

- Опрос HID больше не оставляет незавершённые overlapped-запросы: при
  таймауте запрос отменяется и дожидается завершения. Это убирает риск порчи
  памяти и падения Explorer на спящей мыши.
- Закрытие виджета больше не может подвесить оболочку: Bluetooth/WinRT-вызовы
  ограничены таймаутом и отменяются по сигналу остановки, а колбэки
  Bluetooth-вотчера безопасно отключаются от монитора.
- DLL полностью выгружается при закрытии виджета. Повторный запуск и
  обновление файлов работают без перезапуска Explorer.
- Отчёт диагностики собирается в фоновом потоке: HID-дамп и PnP-опрос больше
  не «замораживают» виджет на несколько секунд.

### Производительность

- Раскладка ячеек и UI Automation перенесены в фоновый поток и обновляются по
  событиям оболочки; лишние перемещения окна не выполняются.
- Пульсация низкого заряда/зарядки длится минуту после смены состояния, а не
  крутит 30 кадров в секунду часами.
- Плитка наушников перерисовывается только когда пульсирует она сама.
- BLE-скан без обнаруженных AirPods идёт раз в две минуты вместо 30 секунд.

### Наушники

- Видимость плитки больше не зависит от имени Bluetooth-устройства:
  переименованные AirPods определяются по адресу из Apple-рекламы.
- «Скрыть виджет» запоминается и держится до реального отключения наушников;
  события устройств больше не возвращают скрытую плитку.
- Добавлен сторож от «залипшего» состояния Connected: полчаса без рекламы —
  и плитка больше не висит вечно.
- Полноэкранный режим проверяется только на мониторе панели задач: игра на
  втором мониторе не прячет виджет на первом.

### Прочее

- Нулевой заряд PnP-устройства считается настоящим (раньше 0 % отбрасывался).
- Журнал ротируется по размеру и обрезает слишком длинные строки вместо
  аварийного завершения.
- Инжектор показывает причину, если виджет не удалось запустить.

## Установка

1. Скачайте ZIP и распакуйте в постоянную папку (например,
   `%LOCALAPPDATA%\BatteryInTaskBar`).
2. Закройте старый виджет через меню мыши («Закрыть виджет»), если он запущен.
3. Запустите `injector.exe`.

## SmartScreen

SmartScreen может предупредить при первом запуске — это нормально.

## Проверка целостности

```powershell
Get-FileHash .\taskbar_mod.dll, .\injector.exe -Algorithm SHA256
```

Сверьте с `SHA256SUMS.txt`.
