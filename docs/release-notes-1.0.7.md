## Исправления и новые функции

- VXE R1 Pro Max / ATK VXE R1 Pro Max: заряд больше не должен залипать
  на 100 % после ложного переключения на запасную команду.
- Плавная анимация наведения на кнопки проверки и установки обновлений.

## Важно
- Это **бета-версия**. На GitHub latest остаётся 1.0.6, поэтому автообновление
  не предложит 1.0.7 — установите ZIP вручную.
- Папка программы должна быть записываемой (не `Program Files` и т.д).

## Установка

1. Скачайте ZIP и распакуйте в постоянную папку (например,
   `%LOCALAPPDATA%\BatteryInTaskBar`).
2. Закройте старый виджет через меню мыши («Закрыть виджет»), если он запущен.
3. Запустите `injector.exe`.

## SmartScreen

SmartScreen может предупредить при первом запуске — это нормально.

## Проверка целостности

```powershell
Get-FileHash .\taskbar_mod.dll, .\injector.exe, .\updater.exe -Algorithm SHA256
```

Сверьте с `SHA256SUMS.txt`.
