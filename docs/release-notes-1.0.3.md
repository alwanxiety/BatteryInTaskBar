# BatteryInTaskBar 1.0.3

Исправление: виджет больше не пропадает при работе с панелью задач.

## Что изменилось

- Всплывающие окна оболочки Windows 11 — превью задач, Task View / Alt+Tab,
  календарь, быстрые настройки и переполнение трея — занимают весь монитор и
  раньше принимались за полноэкранное приложение. Теперь они исключены:
  виджет остаётся на месте, опрос HID не приостанавливается.
- Настоящие полноэкранные игры и видео по-прежнему скрывают виджет и
  останавливают опрос, как и раньше.

## Установка

1. Скачайте ZIP и распакуйте в постоянную папку (например,
   `%LOCALAPPDATA%\BatteryInTaskBar`).
2. Закройте старый виджет через меню мыши («Закрыть виджет»), если он запущен.
3. Запустите `injector.exe`.

## SmartScreen

SmartScreen может предупредить при первом запуске — это нормально.

## Проверка целостности

```powershell
Get-FileHash .\taskbar_mod.dll, .\injector.exe -Algorithm SHA256
```

Сверьте с `SHA256SUMS.txt`.
