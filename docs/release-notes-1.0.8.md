# BatteryInTaskBar 1.0.8 — тест автообновления

Это тестовая сборка для проверки обновления с 1.0.7. Функционально совпадает
с 1.0.7; основное изменение — обновлятор теперь сравнивает релиз с версией
**установленного виджета** (`taskbar_mod.dll`), а не с версией самого
`updater.exe`. Без этого старый обновлятор после установки 1.0.8 снова видел
бы «доступно 1.0.8» и показывал точку.

## Как проверить

1. Установить 1.0.7 (или использовать уже установленную).
2. Открыть меню мыши → внизу нажать **↻**.
3. В футере появится **«Обновление 1.0.8»**, на стрелке — синяя точка.
4. Нажать **↑**. Виджет тихо обновится и перезапустится.
5. После обновления в меню должно быть **«Версия: 1.0.8»**, а синяя точка
   должна исчезнуть после следующей проверки.

## Что внутри

- `taskbar_mod.dll` 1.0.8;
- `injector.exe` 1.0.8;
- `updater.exe` 1.0.8;
- `SHA256SUMS.txt` для проверки загрузки.

Бинарники без подписи: SmartScreen может предупреждать. Папка программы
должна быть записываемой. Журнал обновлятора:
`%LOCALAPPDATA%\BatteryInTaskBar\updater.log`.
