# BatteryInTaskBar 1.0.5

Исправление неверного заряда на мышах ATK / VXE.

## Что изменилось

- Заряд больше не «залипает» на 100 %: провайдер дважды подтверждает ответ
  устройства, поэтому случайный отчёт движения мыши (у которого совпадает
  эхо команды) больше не принимается за заряд.
- Флаг зарядки принимается только как 0/1, а кэш команды `0x04/0x17` привязан
  к конкретному устройству.
- Более точный провайдер (RedSquare) больше не уступает менее точному (Compx)
  на том же интерфейсе; PnP-кэш Windows не подменяет показания, если
  вендорский провайдер уже отвечал за это устройство.
- Эвристика Compx тоже читает значение дважды и требует одинаковый результат.

## Установка

1. Скачайте ZIP и распакуйте в постоянную папку (например,
   `%LOCALAPPDATA%\BatteryInTaskBar`).
2. Закройте старый виджет через меню мыши («Закрыть виджет»), если он запущен.
3. Запустите `injector.exe`.

## SmartScreen

SmartScreen может предупредить при первом запуске — это нормально.

## Проверка целостности

```powershell
Get-FileHash .\taskbar_mod.dll, .\injector.exe -Algorithm SHA256
```

Сверьте с `SHA256SUMS.txt`.
