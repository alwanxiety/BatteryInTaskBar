# BatteryInTaskBar 1.0.9 — тест автообновления

Тестовая цель для проверки обновления **1.0.8 → 1.0.9**. Функционально
совпадает с 1.0.8. Нужна, чтобы проверить кнопку проверки и тихую установку
обновления из меню виджета.

## Как проверить

1. Установите **1.0.8** (это базовая сборка с исправленным обновлятором).
2. Запустите виджет и откройте меню мыши.
3. Внизу нажмите **↻**. В футере должно появиться **«Обновление 1.0.9»**,
   на стрелке — синяя точка.
4. Нажмите **↑**. Виджет тихо обновится и перезапустится.
5. После обновления в меню должно быть **«Версия: 1.0.9»**, а после
   следующей проверки точка должна исчезнуть.

Если обновляться напрямую с 1.0.7, старый `updater.exe` останется в папке
и может продолжать показывать точку. Поэтому базовая 1.0.8 ставится один
раз вручную; дальше обновления идут из меню.

## Что внутри

- `taskbar_mod.dll` 1.0.9;
- `injector.exe` 1.0.9;
- `updater.exe` 1.0.9;
- `SHA256SUMS.txt`.

Бинарники без подписи: SmartScreen может предупреждать. Папка программы
должна быть записываемой. Журнал: `%LOCALAPPDATA%\BatteryInTaskBar\updater.log`.
