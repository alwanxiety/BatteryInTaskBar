# BatteryInTaskBar 1.0.1

Исправление поведения плитки наушников.

## Что изменилось

- Плитка AirPods / Beats больше не мерцает и не появляется фантомно.
  Видимость теперь зависит только от того, считает ли Windows наушники
  подключёнными; BLE-реклама обновляет только заряд.
- Плитка появляется сразу при подключении (из кэша или с «…» до первого
  чтения) и исчезает сразу при отключении устройства.
- В полноэкранной игре плитка скрывается вместе с виджетом, как плитка мыши,
  но её состояние не сбрасывается. После выхода она сразу возвращается и не
  ждёт новой рекламы.

## Установка

1. Скачайте ZIP и распакуйте в постоянную папку (например,
   `%LOCALAPPDATA%\BatteryInTaskBar`).
2. Запустите `injector.exe`.
3. Если виджет уже запущен, закройте его через меню мыши («Закрыть виджет»)
   и запустите `injector.exe` заново.

## SmartScreen

SmartScreen может предупредить при первом запуске — это нормально.

## Проверка целостности

```powershell
Get-FileHash .\taskbar_mod.dll, .\injector.exe -Algorithm SHA256
```

Сверьте с `SHA256SUMS.txt`.
